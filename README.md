# 🥗 Aam – Customer Website

![React](https://img.shields.io/badge/React-Frontend-blue?logo=react)
![Tailwind](https://img.shields.io/badge/Tailwind-CSS-blue?logo=tailwindcss)

![Deployed](https://img.shields.io/badge/Deployed-Vercel-success)

This is the public-facing interface of **Aam** — a modern and responsive food ordering experience for customers.

---

## ✨ Features

- ✅ Browse food categories and products
- 🛒 Add items to cart and place orders
- 📍 Use location for delivery
- 🔐 Authentication
- 📱 Fully responsive design
- 🔔 Toast notifications for feedback

---

## 🛠 Tech Stack

- React + Vite
- React Router DOM
- Tailwind CSS
- Axios
- React Toastify
- Context API for global state
- Firebase or Cloudinary for media (fetched via API)


## 📁 Folder Structure

Food-FrontEnd/ │ ├── src/ │ ├── components/ # UI components │ ├── pages/ # Route components │ ├── context/ # Global state management │ ├── utils/ # Helpers and API functions │ └── App.jsx │ ├── public/ └── vite.config.js
